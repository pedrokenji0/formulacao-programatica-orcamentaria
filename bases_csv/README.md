# Bases CSV do protótipo

Coloque aqui as bases tabulares que alimentam os seletores e importações do protótipo. A aplicação ainda roda 100% no navegador, então estes arquivos servem como organização da base local e referência de nomes/colunas para importação futura.

## 1. Classificador de despesa

Pasta: `bases_csv/classificador_despesa/`

Use um CSV por aba/tabela do classificador:

- `grupos_despesa.csv`
- `elementos_despesa.csv`
- `elementos_itens_despesa.csv`
- `agrupamentos_despesa.csv`
- `fontes_recursos.csv`
- `funcoes.csv`
- `subfuncoes.csv`
- `iag.csv`

## 2. Bases OBZ

Pasta: `bases_csv/obz/`

Use uma base por órgão/unidade ou por rodada:

- `base_obz_modelo.csv`
- `base_obz_1261_see.csv`
- `base_obz_1451_sejusp.csv`
- `base_obz_1501_seplag.csv`
- `base_obz_4291_fes.csv`

## 3. Planejamento qualitativo

Pasta: `bases_csv/planejamento/`

As quatro tabelas esperadas hoje:

- `programas.csv`
- `acoes.csv`
- `localizadores.csv`
- `unidades_orcamentarias.csv`

Mantenha codificação UTF-8 e separador vírgula. Se o CSV vier com ponto e vírgula, importe depois convertendo ou padronizando o separador.
